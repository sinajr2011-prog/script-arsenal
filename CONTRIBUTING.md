# Contributing to Script Arsenal 🛠️

Thanks for wanting to contribute! Every useful script makes this repo stronger.

## How to add a script

1. Fork the repo
2. Create a new branch: `git checkout -b add-my-cool-script`
3. Put your script in the right folder (`bash/git/`, `bash/system/`, `python/`, etc.)
4. Make sure it has:
   - Clear comments
   - Usage example at the top
   - Error handling where possible
5. Update the README if needed (add it to Featured Scripts)
6. Open a Pull Request

## Script Guidelines

- Keep it focused (one job per script)
- Prefer bash for simple tasks, Python when needed
- Avoid hard-coded paths if possible
- Test it before submitting 🙏

## Code of Conduct

Be respectful. We're all here to help each other get more done with less friction.

Happy scripting! 🔥
