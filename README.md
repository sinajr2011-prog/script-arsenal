## 🚀 Quick Start

```bash
# Clone the arsenal
git clone https://github.com/sinajr2011-prog/script-arsenal.git
cd script-arsenal

# Make scripts executable (example)
chmod +x bash/git/*.sh
```

## 🔥 Featured Scripts

### Git Helpers
- `git-cleanup.sh` → Clean merged branches + prune
- `git-sync.sh` → Pull + push with one command

### System
- `disk-usage.sh` → Pretty disk usage report
- `cleanup-temp.sh` → Safe temp & cache cleaner

### Productivity
- `daily-standup.sh` → Generate a quick standup summary from git
